⚔️ Ascension classée

Deux progressions : les XP font monter ton niveau permanent; les RP font avancer tes divisions de Fer IV à Challenger. Ce classement mesure tes quêtes accomplies, il ne compare pas les utilisateurs.

Avant activation : règles V3 conservées. Après activation : les RP sont clôturés chaque jour selon les quêtes exigibles. Le repos complet protégé est neutre. 100 RP par division, puis 200 RP entre les rangs Maître, Grand maître et Challenger. Les transformations acquises restent disponibles.
